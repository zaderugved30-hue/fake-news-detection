# 📰 Fake News Detection

A web-based application that detects whether news is **Real or Fake** using **Machine Learning and Natural Language Processing (NLP)**.

## 🚀 Features

- 🤖 Machine Learning & NLP based detection
- ⚡ Real-time prediction
- 🌐 Flask web interface
- 🔍 Real / Fake classification
- 🎨 Simple and user-friendly UI

## 🛠 Tech Stack

`Python` `Flask` `Machine Learning` `NLP` `HTML` `CSS`

## ⚙️ Installation & Setup

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/zaderugved30-hue/fake-news-detection.git
cd fake-news-detection
```
### 2️⃣ Create Virtual Environment

```bash
python -m venv .venv
```
### 3️⃣ Activate Virtual Environment

**Windows:**

```bash
.venv\Scripts\activate
```
### 4️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```
### 5️⃣ Run the Application

```bash
python app.py
```

## 🔄 How It Works

**Enter News → Text Processing → ML Model → Real / Fake Prediction**
