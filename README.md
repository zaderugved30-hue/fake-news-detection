# 📰 Fake News Detection

A web-based application that detects whether a news article is **Real** or **Fake** using **Machine Learning and Natural Language Processing (NLP)**.

## 🚀 Features

- Real and Fake News classification
- Machine Learning & NLP based detection
- Real-time prediction
- Simple Flask web interface
- Clean and user-friendly design

## 🛠 Tech Stack

`Python` `Flask` `Machine Learning` `NLP` `HTML` `CSS`

## 🔄 How It Works

**Enter News → Text Processing → ML Model → Real / Fake Prediction**
